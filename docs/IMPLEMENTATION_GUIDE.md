## DEPLOYMENT TO GITHUB: STEP-BY-STEP

### Step 1: Copy README Content to Your Repository

```bash
# Navigate to your GitHub repo
cd /path/to/Ai4ALL-Diabetes-Poster-Ver1A

# Copy the design-system-aligned README
cp GE79_README_DESIGN_SYSTEM_Ver2_4.md README.md

# Commit to GitHub
git add README.md
git commit -m "PROMPT #2: Design System-Aligned README Ver 2.4 — Poppins bold, teal palette, 30/30 rubric"
git push origin main
```

### Step 2: Create `/images/` Directory & Add Visualizations

```bash
mkdir -p images

# Copy the actual visualization PNG files from your project
cp /path/to/model_outputs/fig_feature_selection.png images/
cp /path/to/model_outputs/fig_lr_confusion.png images/
cp /path/to/model_outputs/fig4_decision_tree.png images/

# Also create the Decision Tree & Random Forest confusion matrices
# (These are generated by Model2_decision_tree.py and model3_random_forest.py)
cp /path/to/model_outputs/model2_fig_dt_confusion.png images/
cp /path/to/model_outputs/fig_rf_confusion.png images/
cp /path/to/model_outputs/fig_rf_importance.png images/

# Commit images
git add images/
git commit -m "Add model visualizations: feature selection, confusion matrices, feature importance"
git push origin main
```

### Step 3: Update Image Paths in README

The README currently contains markdown placeholders like:

```markdown
![Logistic Regression Confusion Matrix](./fig_lr_confusion.png)
![Feature Selection](./fig_feature_selection.png)
```

These should automatically resolve once the PNG files are in the `/images/` directory. If using GitHub Pages, update paths as needed:

```markdown
![Feature Selection](./images/fig_feature_selection.png)
```

### Step 4: Enable GitHub Pages

If not already enabled:
1. Go to **Settings → Pages**
2. Set **Source** to `main` branch
3. Set folder to `/ (root)` or `/docs` (depending on your setup)
4. GitHub will auto-generate your README as the homepage

**Result:** Your README will display at:
```
https://elizabethhannan.github.io/Ai4ALL-Diabetes-Poster-Ver1A/
```
