# GE-79 MCI Research Poster

Static, responsive GitHub Pages poster for the AI4ALL Summer Cohort 2026 project.

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css`, and `script.js` to the root of the poster repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

No installation or build command is required.

## Edit content

- Poster wording and links: `index.html`
- Colors, spacing, cards, and responsive layout: `styles.css`
- Chart values and mobile navigation: `script.js`

The model metric values in `script.js` are whole-number percentages and should be replaced if the final exported model results change.
